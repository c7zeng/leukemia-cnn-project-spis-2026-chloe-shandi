This is the code for Chloe Zeng and Shandi Chen's final project for the University of California San Diego's Summer Program for Incoming Students (SPIS). Roughly 10,000 blood cell scans were used to train a convolutional neural network (CNN) so that the model could analyze and determine whether the scan displayed signs of acute lymphoblastic leukemia (ALL). The model achieved a final mean balanced accuracy of 72.33%, which indicates it performed better than chance but could be further improved before implementation in a lab setting. Further details about this project can be found in the lab file under the templates folder in this repository.
